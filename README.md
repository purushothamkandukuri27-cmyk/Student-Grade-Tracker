Student Grade Tracker

Project Overview

A beginner-friendly Java application that manages student marks and generates a performance report.

Features

- Enter student names and marks
- Calculate grades (A, B, C, D, F)
- Display Pass/Fail status
- Calculate average, highest, and lowest marks
- Save student reports to a text file

Technologies Used

- Java
- VS Code
- File Handling
- Object-Oriented Programming (OOP)

How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile using "javac StudentGradeTracker.java".
5. Run using "java StudentGradeTracker".
